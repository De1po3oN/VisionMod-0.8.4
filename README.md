# Vision Mod 0.8.4 — Low Fire crash hotfix

**Status:** исходники, не подтверждённая сборка и не проверенный релиз. Требуется Minecraft Java 1.21.11, Fabric Loader 0.19.3+, Fabric API 0.141.6+1.21.11 и Java 21.

## Исправления 0.8.4
- Исправлена компиляция `CompactHandMixin.java` на Minecraft 1.21.11: вместо удалённого `SwordItem` используется `ItemTags.SWORDS`.
- Исправлена компиляция Armor HUD: вместо `getArmorSlots()` используются `getItemBySlot(EquipmentSlot)` для четырёх слотов брони.
- Не меняет меню и 51 назначаемую команду версии 0.8.2.
- Полная Gradle-сборка и тест запуска пока НЕ подтверждены. Требуется GitHub Actions.

## Изменения 0.8.2

- **51 назначаемое действие**: 7 Visuals, 16 Extras, 10 типов руд, 4 фильтра частиц, 3 пресета FPS, 5 изменяемых параметров Performance, 3 переключателя Performance, 3 настройки Zoom/цветов.
- **MMB по функции** открывает назначение клавиши/кнопки мыши на страницах Visuals, Ores, Extras, Performance и Particles. Нажатие ESC в режиме захвата очищает привязку.
- Дополнительные страницы: Extras 3/3 (скорость Zoom / цвета), Performance 1/2 и 2/2 (пресеты / переключатели / числовые ограничения).
- Клавиши Free Look и Zoom работают на удержание, остальные — по одному нажатию.
- Старые JSON-конфиги версии 0.8.1 с **33 биндами** по-прежнему импортируются; новые конфиги содержат 51.
- Открытие меню и быстрое включение всего Vision Mod назначаются в Minecraft Controls. Действия удаления профилей и ввода текста намеренно не имеют горячих клавиш.

Подробная инструкция: `KEYBINDS_RU.md`.

## Изменения 0.8.1

- Единый полностью отрисовываемый Vision Mod интерфейс с боковой навигацией: Visuals, Ores, Extras, Performance, Configs. Без стандартных игровых кнопок на основной странице и без лишнего framebuffer blur.
- **Средняя кнопка мыши (MMB) по модулю:** нажми нужную кнопку/клавишу для бинда. ESC удаляет бинд, повторный MMB привязывает саму среднюю кнопку мыши. Для Free Look и Zoom назначенная клавиша действует при **удержании**, для остальных модулей — **переключатель**.
- Бинды сохраняются в `config/visionmod/hotkeys.properties` и экспортируются в JSON-конфиги вместе с остальными настройками.
- Free Look и Zoom по умолчанию удерживаются на **Left Alt** и **C**, соответственно. Эти две клавиши переназначаются теперь в самом меню через MMB.
- Адаптивная нагрузка: количество локальных игроков и среднее время кадра ограничивают бюджет сканирования руд, радиус поиска, контуры, удалённую косметику и локальные декоративные частицы.
- Пункт «Shulker Tooltip» показывает текстовый список предметов из шалкера при наведении в инвентаре (до 12 первых стопок + итог). Это **не** сетка 9×3 и не полная замена отдельного мода.
- Дополнительная оптимизация Player Hearts: не выделять массивы HP при выключенной функции.
- Сохранились: подсветка руд с выбором типов и цветов, конфиги, эффекты, HUD, звук стрелы, режимы производительности, Free Look, Zoom, прежняя скрытая косметика.
- Подписи внизу: `TG: @cocok_ali` и `For: mc.showtime.su`.

## Управление

Открыть Vision Mod: **Right Shift**. Быстро выключить весь мод: **End**. Выбирай страницу слева, ЛКМ переключает модуль, ПКМ — настройки руд/прицела, **MMB — назначить клавишу**. Клавиши отдельных модулей можно нажимать во время игры, но не при открытом меню.

## Конфиги

В меню открой Configs → **OPEN CONFIGS FOLDER**. Сохрани свой JSON, положи чужой JSON в папку, нажми REFRESH и LOAD SELECTED. Секреты Cloudflare/косметики в конфиги не входят.

## Ограничения

- Это **не готовый Fabric JAR**. Из-за отсутствия доступа к внешнему Maven в текущем окружении сборка `gradle clean build` и запуск Minecraft не проверены. Проверена только синтаксическая структура всех Java-файлов, локальные JSON и ZIP.
- Ускорение **только клиента и кода Vision Mod**. Не улучшает серверный TPS и не заменяет Sodium, Entity Culling и другие оптимизаторы.
- По плану из 21 задачи ещё **не реализованы внутри Vision Mod**: полная анимация тотема, реальное растягивание разрешения, полноценная замена неба с Iris, полноценный JEI, First-person Model. Аналоги AppleSkin/ArmorGlance и Shulker Tooltip пока облегчённые.
- Некоторые экспериментальные миксины из предыдущих версий могут оказаться несовместимыми с шейдерами, Emotecraft и отдельными модами камеры. Требуется тест `latest.log` на реальной сборке.
