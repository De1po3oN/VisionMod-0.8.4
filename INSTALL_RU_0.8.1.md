# Установка Vision Mod 0.8.1 — исходный проект

1. Скачай полный ZIP, распакуй. Внутри должны быть `build.gradle`, `src/` и **скрытая** `.github/workflows/build.yml`.
2. Открой свой репозиторий `https://github.com/De1po3oN/Visionmod-0.6.0`. Можно переименовать его в Visionmod-0.8.1 в Settings, но это необязательно.
3. Загрузи содержимое проекта, не отдельный ZIP. Старые файлы с теми же именами замени новыми; не оставляй дубликаты классов и версии VisionMod.
4. Нажми **Commit changes**. В Actions проверь **Build Vision Mod 0.8.1** → последний запуск → ошибки `:compileJava`, если они есть.
5. Только если сборка зелёная, скачай **Artifact VisionMod-0.8.1**, извлеки `.jar` (не `-sources`/`-dev`) и помести в `mods`.
6. Для Fabric 1.21.11 используй Fabric Loader 0.19.3+ и совместимый Fabric API. В TLauncher выбери правильный профиль.
7. Проверь с выключенными шейдерами, затем включи Iris. Протестируй клавиши и FPS на спавне, сравнив F3 при одинаковой дистанции прорисовки.

**Важно:** сборка к этому моменту не подтверждена, поэтому нельзя утверждать, что JAR гарантированно запустится. Если возникнет ошибка, приложи текст от `> Task :compileJava` до `BUILD FAILED`.
